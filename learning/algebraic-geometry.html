    正特征代数几何笔记

    ← Learning

    本笔记整理自研究 quasi-elliptic surface 上的 Bogomolov 型不等式过程中积累的背景知识与证明技术，相关结果见 论文页。面向有代数几何基础（熟悉概形、上同调）的读者。

    引言：正特征是一个试验场

    代数几何中有一类基本问题：经典定理在正特征域上是否仍然成立？有时答案是肯定的，但证明需要完全不同的方法。有时答案是否定的，而反例本身就揭示了特征 0 情形中被隐藏的几何结构。

    Bogomolov 不等式属于第一类。它在特征 0 中有优雅的证明，但将其推广到正特征需要理解 Frobenius 态射与向量丛稳定性的相互作用。当曲面具有 quasi-elliptic 纤维结构时，这个相互作用变得格外微妙——因为 quasi-elliptic fibration 本身是一种仅在特征 2 和 3 中存在的现象。

    这份笔记从向量丛的基础讲起，逐步建立理解这一问题所需的所有工具：斜率稳定性、Bogomolov 不等式、Frobenius 态射、quasi-elliptic 纤维化，以及经典证明失效的具体位置。

    预备知识一：向量丛与稳定性

    向量丛的基本不变量

    设 S 是代数闭域 k 上的光滑射影曲面，E 是 S 上的秩为 r 的向量丛。E 的主要数值不变量是 Chern 类：

    • c1(E) ∈ Pic(S) — 第一 Chern 类，对应行列式线丛 det(E) = ∧rE
    • c2(E) ∈ H4(S, ℤ) ≅ ℤ — 第二 Chern 类
    • 判别式 Δ(E) = 2r · c2(E) − (r−1) · c1(E)2

    对于 End(E)，有 c2(End(E)) = 2r · c2(E) − (r−1) · c1(E)2 = Δ(E)，因此判别式等于内自同态丛的第二 Chern 类。

    斜率稳定性（Mumford-Takemoto）

    固定 S 上的一个丰沛因子 H（极化）。向量丛 E 的（关于 H 的）斜率定义为

    μ(E) = (c1(E) · H) / rank(E)

    其中 c1(E) · H 是交叉数。

    定义（斜率稳定性）：向量丛 E 称为 H-半稳定的，若对 E 的所有秩小于 r 的子层 F ⊂ E，有 μ(F) ≤ μ(E)。若不等式严格，则称 E 是稳定的。

    半稳定性关于张量积和对偶表现良好：若 E 和 F 均为半稳定，则 E ⊗ F 亦半稳定。每个向量丛有唯一的 Harder-Narasimhan 滤链，其逐步商为半稳定丛。

    Riemann-Roch 公式

    光滑射影曲面上的 Hirzebruch-Riemann-Roch：

    χ(S, E) = rank(E) · χ(OS) + (c1(E) · (c1(E) − KS)) / 2 − c2(E)

    其中 KS 是典范除子，χ 是 Euler 特征数 h0 − h1 + h2。将此公式应用于 E = End(F)，即得判别式 Δ(F) 出现的自然场景。

    Bogomolov 不等式：特征 0 的经典情形

    定理陈述

    定理（Bogomolov，1978）：设 k 是特征 0 的代数闭域，S 是 k 上的光滑射影曲面，H 是丰沛因子。若 E 是 H-半稳定向量丛，则

    Δ(E) = 2r · c2(E) − (r−1) · c1(E)2 ≥ 0

    等号成立当且仅当 E 是某个线丛的直和（在 étale 覆叠后）。

    特征 0 证明的核心思路

    主要有两种方法：微分几何方法（Kobayashi-Hitchin 对应）和代数方法（Mehta-Ramanathan 限制定理）。

    代数方法的关键步骤：

    1. 限制定理（Mehta-Ramanathan）：若 E 是 H-半稳定的，则 E 在一般的 H-超平面截面曲线 C ⊂ S 上的限制 E|C 仍是半稳定的。
    2. 向量丛的正定性：对曲线上的半稳定丛，利用 Riemann-Roch 和上同调消没，可以证明 End(E|C) 在代数意义上是"正"的。
    3. 提升到曲面：将曲线上的结论通过 Hodge 指标定理提升，得到 Δ(E) ≥ 0。

    在特征 0 中，步骤 1 中的限制定理有较强形式：对充分一般的截面，保持稳定性。这依赖于特征 0 情形下 Frobenius 不存在所带来的"可分性"。

    Frobenius 态射

    定义与基本性质

    设 k 是特征 p > 0 的域，X 是 k 上的概形。X 的绝对 Frobenius 态射 Fabs: X → X 定义为：在拓扑空间上是恒等映射，在结构层上是 f ↦ fp。

    由于 f ↦ fp 不是 k-代数同态（除非 k 是完全域），更自然的是考虑相对 Frobenius。设 X(p) 是 X 通过 Frobenius Fk: k → k（a ↦ ap）的基变换。相对 Frobenius F = FX/k: X → X(p) 是 k-态射。

    关键性质：

    • 对线丛 L：F*L = L⊗p，即 c1(F*L) = p · c1(L)
    • 对向量丛 E：rank(F*E) = rank(E)，且 c1(F*E) = p · c1(E)
    • Frobenius 拉回一般不保持稳定性：即使 E 半稳定，F*E 也可能不稳定

    Frobenius 稳定性（强稳定性）

    在正特征中，这导致一个重要的稳定性分层：

    • 半稳定（semistable）：标准的 Mumford-Takemoto 定义
    • Frobenius 半稳定（F-semistable / strongly semistable）：E 称为强半稳定，若 (Fn)*E 对所有 n ≥ 1 均半稳定

    强半稳定是更强的条件。强半稳定的向量丛对 Bogomolov 不等式满足一个更清晰的版本：若 E 是强半稳定的，则 Δ(E) ≥ 0（这在任意特征下均成立）。

    对于一般的半稳定丛 E（非强），其 Frobenius 拉回序列 (Fn)*E 的 Harder-Narasimhan 滤链最终稳定，对应的"Frobenius 不稳定性"可以用 p-curvature 或 Higgs 场来描述。这是 Langer、Mehta-Pauly 等人工作的主题。

    Quasi-Elliptic Fibrations

    椭圆纤维化与 quasi-elliptic 纤维化

    设 f: S → C 是光滑射影曲面到光滑射影曲线的态射，且一般纤维光滑连通。若一般纤维是亏格 1 的光滑曲线（即椭圆曲线），则称 f 是椭圆纤维化（elliptic fibration）。

    Quasi-elliptic fibration 则不同：一般纤维是具有一个尖点（cusp）奇点的有理曲线，其算术亏格为 1 但几何亏格为 0。具体地，一般纤维同构于仿射曲线 y2 = x3（特征 2 情形）或 y2 = x3（某些特征 3 情形），加上"无穷远点"。

    为什么仅在特征 2 和 3 中存在

    在特征 0 或特征 ≥ 5 中，不存在 quasi-elliptic fibration。原因与可分性有关：

    尖点有理曲线的正规化映射 ℙ1 → （尖点曲线）在特征 ≠ 2, 3 中是可分态射，因此通过一般纤维总可以找到"内嵌的光滑曲线"（截面），矛盾于纤维的几何亏格。

    在特征 2 中，映射 t ↦ (t2, t3) 是不可分的（度数 2 的纯不可分映射），使得尖点曲线成为合理的"亏格 1 对象"。类似地，特征 3 中也有对应构造。这种不可分性正是 Frobenius 的影响。

    Quasi-elliptic 曲面的几何性质

    具有 quasi-elliptic 纤维化的曲面（quasi-elliptic surface）具有以下特征性质：

    • Kodaira 维数：κ(S) = 1（恰好是"准椭圆"情形）
    • 典范丛公式：与椭圆情形类似，但需要处理不可分纤维化的贡献项
    • 奇异纤维：具有特殊的奇异类型，Kodaira 分类在此情形部分适用、部分需要修正
    • Frobenius 行为：由于纤维结构是不可分的，Frobenius 态射沿纤维方向的作用与椭圆情形根本不同

    Quasi-elliptic surface 是正特征代数几何中少数几个"本质上不同于特征 0"的现象之一，它们的存在来自于特征 2 和 3 中可分与不可分之间的特殊性质。

    为什么经典 Bogomolov 证明在此失效

    问题的具体位置

    将特征 0 的 Bogomolov 证明推广到正特征，通常依赖以下思路：

    1. 若 E 是强半稳定的，直接得到 Δ(E) ≥ 0
    2. 若 E 不是强半稳定的，找到一个 n 使得 (Fn)*E 的 Harder-Narasimhan 滤链给出 destabilizing subsheaf，再用 Bogomolov-Gieseker 不等式的曲线版本得到约束。

    这个策略在一般曲面上（对特征 p 充分大）可以执行。然而在 quasi-elliptic 曲面上，步骤 2 遇到了根本性障碍：

    障碍 1：纤维上 Frobenius 的不可分性。Quasi-elliptic fibration f: S → C 的一般纤维 Xη 是一个尖点有理曲线，其正规化 ν: ℙ1 → Xη 是度数 p 的纯不可分映射。因此，从 ℙ1 上的向量丛推送下来的向量丛，在限制到纤维后其 Frobenius 拉回会产生额外的 destabilization，而这种 destabilization 的幅度不容易被控制。

    障碍 2：截面的缺失。在标准的椭圆纤维化中，截面 σ: C → S 提供了丰富的几何结构（Mordell-Weil 群等）。Quasi-elliptic 纤维化一般没有截面（或仅有有限个），这使得许多利用截面进行论证的技术失效。

    障碍 3：曲率与 p-curvature 的关系。正特征中，向量丛的稳定性与其 p-curvature（一种关于 Frobenius 平坦结构的不变量）密切相关。Quasi-elliptic 情形中，p-curvature 沿纤维方向的行为由不可分纤维化所决定，而不是由丛本身的内在结构决定。这打破了通常的"稳定 ⟺ 有界 p-curvature"的直觉。

    一个具体的失效例子

    设 S 是特征 2 上的 quasi-elliptic K3 曲面，f: S → ℙ1 是 quasi-elliptic 纤维化。考虑与纤维结构相关的秩 2 向量丛 E = f*(V) ⊗ L，其中 V 是 ℙ1 上的秩 2 丛，L 是适当选取的线丛。

    E 可以是半稳定的，但 F*E 会因为 Frobenius 沿不可分纤维方向的作用而变得不稳定。此时标准的"迭代 Frobenius 拉回"论证无法给出均匀的界，而需要利用 quasi-elliptic 结构做精细分析。

    主要结果与证明思路

    主要定理

    定理（见 论文）：设 k 是特征 2 或 3 的代数闭域，S 是 k 上的 quasi-elliptic surface，H 是丰沛因子。若 E 是 H-半稳定向量丛，则

    Δ(E) ≥ 0

    即 Bogomolov 型不等式在 quasi-elliptic 曲面上仍然成立。

    证明的基本思路

    证明利用 quasi-elliptic 纤维化 f: S → C 的结构，分两步进行：

    步骤一：沿纤维方向的分析。将 E 限制到 quasi-elliptic 纤维 Xt，利用尖点有理曲线上向量丛的精细分类（以及正规化 ν: ℙ1 → Xt 的不可分性），分析 E|Xt 在 Frobenius 下的行为。关键在于，虽然单个纤维上的 Frobenius 作用是不可控的，但"在 C 上的族"所满足的半连续性给出了足够的约束。

    步骤二：利用纤维化结构做全局论证。将步骤一得到的纤维信息，通过 Leray 谱序列和 Grothendieck-Riemann-Roch（相对版本）提升到全局的 Chern 类等式。关键不等式来自于对 f*(End(E)) 的分析——quasi-elliptic 结构使得这个推出丛在曲线 C 上具有特殊的滤链，从而给出 Δ(E) 的非负下界。

    证明中最精细的部分是处理 野纤维（wild fibers）的贡献。在 quasi-elliptic 情形中，奇异纤维的 Euler 特征数计算包含了来自不可分纤维化的"野"贡献（与正特征中的不可分度相关），需要仔细分离这些贡献并证明它们不破坏 Δ ≥ 0。

    相关背景与拓展

    Bogomolov-Gieseker 不等式与模空间

    Bogomolov 不等式的一个直接推论是向量丛模空间的有界性：秩 r、固定 c1 的 H-半稳定向量丛，其 c2 满足 c2 ≥ ((r−1)/(2r)) · c12（有下界）。这保证了对应的模空间 MS(r, c1, c2) 在 c2 固定时是有限型的，从而可以讨论其 Donaldson-Uhlenbeck-Yau 型结构。

    将这一结果推广到 quasi-elliptic 曲面，为正特征向量丛模空间的研究提供了基础。

    Simpson 对应在正特征中的问题

    在特征 0 中，Kobayashi-Hitchin 对应建立了稳定向量丛（代数几何）与 Hermitian-Einstein 联络（微分几何）之间的等价。正特征中，这个对应由 Ogus-Vologodsky（特征 p 的 Riemann-Hilbert 对应）和 Chen-Zhu 等人的工作替代。在 quasi-elliptic 曲面上，由于不可分纤维化，这种对应的建立更为复杂，是一个开放问题。

    与 Artin 超奇点的关系

    Quasi-elliptic K3 曲面（特征 2 和 3 中的特殊情形）与 Artin 超奇点（supersingular）K3 曲面密切相关。Shioda-Inose 构造在特征 0 中将 K3 曲面与椭圆曲线对联系起来；在特征 2 中，quasi-elliptic 结构替代了椭圆曲线对，反映了 Frobenius 对 Picard 群结构的影响。这是一个活跃的研究方向。
