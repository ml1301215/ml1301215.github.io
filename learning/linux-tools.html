    Linux 服务器实用工具

    ← Learning

    整理自实际在服务器上工作时发现的工具。有些是内置的，有些需要安装。按使用频率排列，最高频的放最前面。

    一、tmux（必装，优先级最高）

    SSH 连接断开时，终端里所有正在运行的进程都会被 kill。tmux 让你的工作在断开后继续运行，下次连上可以无缝恢复。

    # 基本操作
tmux new -s mysession       # 新建会话，命名
tmux ls                     # 列出所有会话
tmux attach -t mysession    # 重新连接到会话

# 快捷键（都以 Ctrl+b 开头）
Ctrl+b, d     # detach，离开会话（会话继续后台运行）
Ctrl+b, c     # 新建窗口
Ctrl+b, n     # 下一个窗口
Ctrl+b, p     # 上一个窗口
Ctrl+b, 数字  # 切换到对应编号的窗口
Ctrl+b, "     # 上下分割当前窗格
Ctrl+b, %     # 左右分割当前窗格
Ctrl+b, 方向键 # 切换窗格

    一个实用的工作流：开一个 tmux 会话，三个窗口分别跑训练脚本、监控 GPU、查看日志。断开 SSH 后训练继续，回来直接 attach。

    二、htop（进程与资源监控）

    比内置的 top 更直观，可以看到每个 CPU 核的使用率、内存、swap，以及进程树。

    sudo apt-get install htop    # 安装
htop                         # 运行

# 在 htop 里：
F5   # 切换树形视图（看进程父子关系）
F6   # 按某个字段排序
F9   # kill 选中的进程
/    # 搜索进程名

    训练时 CPU 内存突然被吃满，htop 可以快速找到是哪个进程在占用。

    三、nvidia-smi（GPU 监控）

    内置于 NVIDIA 驱动，是 GPU 监控最基本的工具。

    nvidia-smi                     # 一次性快照
watch -n 1 nvidia-smi          # 每秒刷新
nvidia-smi --query-gpu=utilization.gpu,memory.used,memory.total \
  --format=csv -l 1            # 只显示关键指标，每秒更新

    nvtop 是更现代的替代品，界面类似 htop，需要单独安装（sudo apt install nvtop），动态可视化更直观。

    四、nohup 和 screen（后台运行）

    如果不想用 tmux，可以用 nohup 让进程在退出后继续运行：

    nohup python train.py > train.log 2>&1 &
# 输出重定向到 train.log，& 放入后台
# 进程 ID 会打印出来，记下来方便之后 kill

    screen 功能类似 tmux 但更简单：

    screen -S train          # 新建会话
screen -ls               # 列出会话
screen -r train          # 重新连接
Ctrl+a, d                # detach

    tmux 功能更丰富（多窗口、分屏），建议优先用 tmux。nohup 适合快速启动一个不需要交互的后台任务。

    五、rsync 和 scp（文件传输）

    # scp：简单文件传输
scp local_file.txt user@server:/remote/path/
scp -r local_dir/ user@server:/remote/path/    # 目录

# rsync：增量同步，适合大量文件
rsync -avz local_dir/ user@server:/remote/path/
# -a：保留权限、时间戳等元信息
# -v：显示进度
# -z：压缩传输
rsync --progress -avz model_weights/ server:/data/weights/

    传输模型权重（几十 GB）时，rsync 比 scp 快很多，因为它只传输变化的部分，断点续传也更可靠。

    六、df 和 du（磁盘使用）

    df -h             # 查看各分区剩余空间（-h 人类可读格式）
du -sh /path/*    # 查看某目录下各子目录的大小
du -sh .          # 查看当前目录总大小

# 找出占用空间最多的目录
du -h --max-depth=1 /data | sort -hr | head -20

    训练中途磁盘满了会导致进程崩溃，且通常没有清晰的报错信息。定期 df -h 检查磁盘，是个好习惯。

    七、tail 和 grep（日志查看）

    tail -f train.log             # 实时跟踪日志文件末尾
tail -n 100 train.log         # 查看最后 100 行
grep "loss" train.log         # 过滤包含 loss 的行
grep -n "Error" train.log     # 显示行号
tail -f train.log | grep --line-buffered "loss"  # 实时过滤

    训练日志通常很长，用 grep 过滤关键词是最快的定位方式。

    八、几个容易忽略但很有用的命令

    free -h               # 内存使用情况（总量、已用、可用、swap）
lscpu                 # CPU 信息（核数、架构）
which python          # 确认当前用的是哪个 Python
pip show torch        # 查看某个包的版本和安装位置
ps aux | grep train   # 找正在运行的训练进程
kill -9 PID           # 强制 kill 进程（PID 从 ps 或 htop 获取）
history | grep conda  # 在历史命令里搜索

    九、别名（alias）省时间

    把常用的长命令存成短别名，放在 ~/.bashrc 或 ~/.zshrc 里：

    # 加入 ~/.bashrc
alias gpu='watch -n 1 nvidia-smi'
alias mem='free -h'
alias py='python3'
alias tl='tail -f'

source ~/.bashrc    # 使改动生效

    这些别名在每次登录时自动加载，之后直接输 gpu 就能监控 GPU，省掉重复打字。
