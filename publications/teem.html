Abstract

Large language models (LLMs) have enabled increasingly capable agents, yet long-horizon conversational memory remains a major challenge. While existing approaches have made progress, they typically treat time as auxiliary metadata, limiting reasoning over evolving interaction histories. We propose TEEM (Time-CEntered Event Memory), a graph-based memory architecture that organizes interaction history around explicit temporal structure. TEEM constructs a temporally grounded memory graph in which temporal segments organize interaction events and link them to supporting evidence and evolving states. At query time, TEEM retrieves and fuses information from complementary memory layers, enabling temporal localization, event-level reasoning, evidence-grounded answering, and reasoning over state changes. Experiments on LoCoMo and LongMemEval show that TEEM consistently improves temporal reasoning and cross-session conversational memory, achieving an overall score of 95.67 on LoCoMo and 87.60 on LongMemEval.
