    Lean 4 formalized proofs of ICCM competition problems and "First Proof" research-level problems, produced as part of the automated AI pipeline described in arXiv:2602.13695. Each problem is formalized as a standalone Lean 4 file with both the problem statement and verified proof.

    ICCM竞赛题目与"首次证明"研究级别题目的Lean 4形式化证明，由arXiv:2602.13695中描述的自动化AI流水线生成。每道题目均形式化为独立的Lean 4文件，包含题目陈述与经过验证的证明。

    Contents 内容 Lean 4 source files (.lean) for ICCM and First Proof problems, verified by lake build ICCM及首次证明题目的Lean 4源文件（.lean），经lake build验证
